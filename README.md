## Selected projects

### [open-digest](https://github.com/yubin-bai/open-digest)

A config-driven LLM digest pipeline with multi-source retrieval, structured-output validation, automated delivery, and model evaluation.

- Retrieves from news, RSS, Reddit, Hacker News, arXiv, JSON feeds, and market data
- Grounds generated items to source URLs and validates structured outputs
- Supports retries, model fallback, CLI/API usage, and scheduled GitHub Actions delivery
- Uses a 20-case LLM-as-judge benchmark to balance quality and cost

### [distributed-edge-storage](https://github.com/yubin-bai/distributed-edge-storage)

A distributed file-storage system deployed across multiple AWS EC2 instances.

- Splits uploads into chunks and assigns each chunk through a pluggable placement policy
- Uses Flask coordination and node servers with a React upload client
- Supports Rainbow-DQN, DQN, greedy, and random placement strategies
- Separates placement decisions from the storage path so policies can be evaluated on the live system
